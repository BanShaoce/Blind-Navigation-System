# 建图指南

以下流程用于 ZED 2i 与 RTAB-Map 的现场建图。命令中的话题名需与实际相机配置一致。

## 1. 启动坐标与相机

```bash
ros2 run tf2_ros static_transform_publisher \
  --x 0 --y 0 --z -0.8 --yaw 0 --pitch 0 --roll 0 \
  --frame-id zed_camera_link --child-frame-id base_link

ros2 launch zed_wrapper zed_camera.launch.py camera_model:=zed2i
```

## 2. 启动 RTAB-Map 增量建图

```bash
ros2 launch rtabmap_launch rtabmap.launch.py \
  rtabmap_args:="--delete_db_on_start \
  --Grid/RangeMax 5.0 --Grid/CellSize 0.05 \
  --Grid/NormalsSegmentation false --Grid/RayTracing true \
  --Grid/MinGroundHeight -0.1 --Grid/MaxGroundHeight 0.15 \
  --Grid/MaxObstacleHeight 2.1 \
  --RGBD/LinearUpdate 0.1 --RGBD/AngularUpdate 0.1" \
  rgb_topic:=/zed/zed_node/rgb/color/rect/image \
  depth_topic:=/zed/zed_node/depth/depth_registered \
  camera_info_topic:=/zed/zed_node/rgb/color/rect/camera_info \
  odom_topic:=/zed/zed_node/odom \
  frame_id:=base_link approx_sync:=true wait_for_transform:=0.5 \
  qos:=1 visual_odometry:=false rtabmap_viz:=false rviz:=false
```

缓慢、平稳地覆盖待导航区域并形成闭环。结束时按 `Ctrl+C`。数据库默认位于 `~/.ros/rtabmap.db`，可用 `ls -lh ~/.ros/rtabmap.db` 检查。

## 3. 检查与导出

在带图形界面的电脑上打开数据库：

```bash
rtabmap-databaseViewer /path/to/rtabmap.db
```

在 `View -> 3D Map` 中检查点云与闭环；必要时使用 `Regenerate`。从 `File -> Export 2D Map (.pgm)` 导出二维地图，栅格分辨率建议保持 `0.05 m`。

PGM 如需人工修补，应保留原始文件，使用无插值的像素工具编辑，并以原尺寸、灰度格式导出。YAML 示例：

```yaml
image: rtabmap3.pgm
resolution: 0.05
origin: [-2.94476, -3.47012, 0.0]
negate: 0
occupied_thresh: 0.5
free_thresh: 0.196
```

## 4. 标定目标点

启动定位和 RViz 后，选择 “Publish Point”，在地图上点击目标位置，并读取：

```bash
ros2 topic echo /clicked_point
```

把坐标写入 `config/navigation.yaml` 的 `destinations`，不要修改 Python 源码。每次换图后都应重新核对目标点与障碍区域。

## 5. 数据管理建议

- 数据库、地图和现场参数应使用同一场地版本号；
- 室内地图可能包含敏感布局，分享前确认授权；
- 大型数据库不宜直接提交 Git，可放到受控对象存储并记录校验值；
- 对原始地图、修补地图和上线地图分别保留只读备份。
