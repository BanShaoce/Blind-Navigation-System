# 运行速查

```bash
source /opt/ros/humble/setup.bash
source ~/ros2_ws/install/setup.bash
export DASHSCOPE_API_KEY='你的密钥'
ros2 launch blind_navigation_system blind_guide.launch.py
```

仅启动导航：

```bash
ros2 launch blind_navigation_system blind_guide.launch.py enable_perception:=false
```

快速诊断：

```bash
ros2 node list
ros2 run tf2_ros tf2_echo map base_link
ros2 topic hz /zed/zed_node/odom
ros2 topic echo /local_costmap/costmap_raw --once
```

日志目录：`~/.ros/log/`。完整说明见 [部署与运行说明](部署与运行.md)。
