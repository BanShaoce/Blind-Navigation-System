1.终端1：ros2 run tf2_ros static_transform_publisher --x 0 --y 0 --z -0.8 --yaw 0 --pitch 0 --roll 0 --frame-id zed_camera_link --child-frame-id base_link
2.终端2：ros2 launch zed_wrapper zed_camera.launch.py camera_model:=zed2i
3.终端3：
ros2 launch rtabmap_launch rtabmap.launch.py \
    rtabmap_args:="--delete_db_on_start \
    --Grid/RangeMax 5.0 \
    --Grid/CellSize 0.05 \
    --Grid/NormalsSegmentation false \
    --Grid/RayTracing true \
    --Grid/MinGroundHeight -0.1 \
    --Grid/MaxGroundHeight 0.15 \
    --Grid/MaxObstacleHeight 2.1 \
    --RGBD/LinearUpdate 0.1 \
    --RGBD/AngularUpdate 0.1" \
    rgb_topic:=/zed/zed_node/rgb/color/rect/image \
    depth_topic:=/zed/zed_node/depth/depth_registered \
    camera_info_topic:=/zed/zed_node/rgb/color/rect/camera_info \
    odom_topic:=/zed/zed_node/odom \
    frame_id:=base_link \
    approx_sync:=true \
    wait_for_transform:=0.5 \
    qos:=1 \
    visual_odometry:=false \
    rtabmap_viz:=false \
    rviz:=false
    
4.不想建了直接ctrl+C，默认情况下，地图文件保存在 Jetson Orin 的这个位置/home/nvidia/.ros/rtabmap.db
ls -lh ~/.ros/rtabmap.db可检查文件大小

5.主机执行scp nvidia@192.168.31.204:~/.ros/rtabmap.db ~/桌面
将.db文件拷贝到主机桌面

6.rtabmap ~/桌面/rtabmap.db打开地图查看器
进入软件后，点击上方菜单栏的 View -> 3D Map（或者直接按键盘数字 3）查看3D建图效果。
如果刚进去看到是黑的，点击左下角的 "Regenerate"（重新生成） 按钮，它会根据数据库里的数据现场渲染出 3D 点云。

7.地图导出：rtabmap-databaseViewer ~/桌面/rtabmap.db
点击上方菜单：File -> Export 2D Map (.pgm)
在弹出的对话框中，确保 Cell size (m) 设为 0.05

8.p图用GNU图像处理程序，铅笔工具，然后导出（不是保存），用raw格式

9.# 传送 .pgm 文件
scp ~/桌面/rtabmap1.pgm nvidia@192.168.31.204:/home/nvidia/nav/
# 传送 .yaml 文件
scp ~/桌面/rtabmap1.yaml nvidia@192.168.31.204:/home/nvidia/nav/

10.orin上直接启动lanuch脚本，pc上用rviz2链接后，终端ros2 topic echo /clicked_point，rviz2上选择publish point点一下目的地就能获取坐标，在nav2.py中搜“#座位、#门口“修改坐标
